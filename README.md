# Disease Diagnosis System

A simple, modern web application for preliminary disease diagnosis based on user-input symptoms. Built with HTML, CSS, and JavaScript, this project helps users:

- Enter their symptoms to get a list of possible diseases.
- View suggested medicines, self-care advice, and the type of doctor to consult for each diagnosis.
- See a history of previous diagnoses for reference.

## Features

- **Easy Symptom Input**: Enter symptoms as comma-separated values for quick diagnosis.
- **Clear Results**: Get a list of possible diseases, recommended medicines, self-care suggestions, and relevant specialists.
- **Diagnosis History**: View your previous diagnosis results in a user-friendly modal.
- **Responsive Design**: Works on both desktop and mobile devices.
- **Modern UI/UX**: Clean, intuitive interface for a seamless user experience.
- **Modular & Scalable Code**: Logic and data are separated for easy updates and future enhancements.

## Getting Started

1. Clone or download the repository.
2. Make sure all files (`index.html`, `styles.css`, `script.js`, `knowledgeBase.js`) are in the same folder.
3. Open `index.html` in your browser.

No installation or backend required!

## Project Structure

- `index.html` – Main HTML file.
- `styles.css` – Responsive, modern styles.
- `script.js` – Main logic (modular, uses ES6+).
- `knowledgeBase.js` – Symptom-disease, medicine, doctor, and self-care data.
